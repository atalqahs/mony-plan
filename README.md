# My Financial Plan — خطتي المالية

تطبيق ويب شخصي (PWA) لإدارة خطة سداد الديون، عربي RTL، مصمم للآيفون على هوية تطبيق Habits.

- بلا خادم ولا تسجيل دخول. البيانات محفوظة على الجهاز (IndexedDB + نسخة مرآة في localStorage) ولا تُمسح عند التحديث.
- يعمل دون إنترنت بعد أول فتح (Service Worker).
- كل المبالغ أعداد صحيحة بالفلس — لا أرقام عائمة في الحسابات. المنطقة الزمنية Asia/Kuwait.

## البنية
| الملف | الدور |
|---|---|
| `js/money.js` | تحويل وعرض الدينار بثلاث منازل (فلس) |
| `js/engine.js` | المحرك: المحاكاة الشهرية، العجز والترحيل، الجدولة التلقائية، الفيزا، السيناريو |
| `js/actions.js` | العمليات مع التحقق وسجل العمليات |
| `js/store.js` | الحفظ المحلي |
| `js/app.js` | الواجهة |

## قواعد المحاسبة الأساسية
- الرصيد الحقيقي = الرصيد المرجعي + التصحيحات − الدفعات **المؤكدة**. الأقساط المستقبلية والعجز لا يُضافان إليه.
- حالات البند: غير مسجل (مجهول) / مسدد جزئيًا / مسدد بالكامل / مسجل بانتظار التأكيد / غير مسدد في شهر مقفل.
- العجز المؤكد ينشأ فقط من دفعة جزئية مسجلة أو من **إقفال الشهر يدويًا** مع مبلغ غير مسدد. لا إقفال تلقائي.
- الأشهر الماضية لا تولّد سيولة. السيولة تبدأ من «الرصيد النقدي المتاح» الذي يُدخله المستخدم (افتراضيًا صفر)، والتدفقات المؤكدة بعد تاريخه، ثم توقعات الشهر الحالي وما بعده.
- المصاريف الأساسية تُحجز كاملة في التوقع حتى إقفال الشهر.
- احتياطي الجامعة تخصيص نقدي في يناير يُصرف منه في فبراير — يخرج من السيولة مرة واحدة.
- الدفعة لها شهر مالي وتاريخ تنفيذ مستقلان. بدل الإيجار مخصص لشهر مالي واحد (افتراضيًا شهر استحقاقه).
- من مارس 2027: المصاريف ← الأقساط الإلزامية ← العجز ← الفائض حسب أولويات السداد (المخالفات ← الأثاث ← ديون الأشخاص المؤكدة الاستحقاق). القرض الصغير والشؤون حسب جدوليهما فقط.
- ديون الأشخاص الأصلية «بانتظار التحقق» ولا تدخل الجدولة حتى يؤكد المستخدم استحقاقها أو يسجل سدادها.
- ترحيل البيانات (`migrate`) يرفع النموذج دون حذف أي شيء.

## التشغيل والاختبار
```bash
python3 -m http.server 8765      # ثم افتح http://localhost:8765
npm test                          # اختبارات المحرك (node:test)
npm run test:e2e                  # اختبار الواجهة (Playwright، يحتاج الخادم أعلاه)
```

## النشر على GitHub Pages
الملف `.github/workflows/pages.yml` يشغّل الاختبارات وينشر الموقع، ويعمل يدويًا فقط (Actions ← Run workflow). قبل أول نشر فعّل:
**Settings → Pages → Source: GitHub Actions**. ثم افتح الرابط في Safari على الآيفون ← مشاركة ← «إضافة إلى الشاشة الرئيسية».
